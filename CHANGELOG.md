# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1] - 2026-10-27

### Added

- Initial release for Minecraft 26.2.
- Packed variants for Cobblestone, Dirt, and Netherrack.
- Full crafting recipes and uncrafting shapeless recipes (9x exchange).
- Dynamic mining tool tags and loot tables via Fabric Data Generation.
- Custom Creative Mode Tab for all packed blocks.
